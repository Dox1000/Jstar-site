Compliance Radar — Privacy Policy

Last updated: 18 September 2026

Compliance Radar is a private, internal tool. It is not a consumer product, it has no sign-up, and it is not offered to the public. This page exists to describe exactly what the tool does with Google account data, as required for its Google API access.

What the tool is

Compliance Radar monitors public regulatory and enforcement sources, compiles what it finds into a daily summary, and emails that summary to one designated internal recipient. It runs on a single private server operated by its author. There are no user accounts and no public interface.

What Google data it accesses

The tool requests exactly one Google OAuth scope:

  • https://www.googleapis.com/auth/gmail.send

This scope permits sending mail on behalf of the authorizing account and nothing else. It confers no ability to read, search, list, label, modify or delete messages. The tool does not read the mailbox, does not access contacts, and does not access any other Google service.

Authorization is granted by the operator to their own Google account. No third party is ever asked to connect an account.

What is sent

A single daily email containing the compiled summary described above. It is sent from the authorizing account to one fixed internal recipient address configured on the server. Recipients are not collected, imported, or derived from any Google data — the address is set by hand in server configuration.

What is stored, and where

  • An OAuth refresh token, held in a permission-restricted file on the operator's private server. It is used solely to obtain short-lived access tokens for sending.
  • A send log recording, per attempt, the timestamp, recipient, subject and success or failure status. This exists so a delivery outage is detected rather than passing silently. It contains no message bodies.

Neither is transmitted anywhere. There is no analytics, no tracking, and no external database.

What is never done

  • Google user data is not sold, rented, or shared with anyone.
  • It is not used for advertising or any form of profiling.
  • It is not used to train machine-learning models.
  • It is not transferred to any third-party service or processor.
  • No mailbox content is read, because the granted scope cannot read it.

Retention

The refresh token is retained until it is revoked or replaced. Send-log entries are retained for operational troubleshooting and may be pruned at any time. Because the tool only sends, there is no accumulated store of Google user data to retain.

Revoking access

The authorizing account can withdraw access at any time at myaccount.google.com/permissions. Revocation takes effect immediately; the tool then stops sending and reports the failure to its operator.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
